
# Homework
## Данный проект содержит практический материал созданный для закрепления полученной теоретической базы на уроках SKYPRO
### Добавлена функция для считывания финансовых операций из CSV выдает список словарей с транзакциями
### Добавлена функция для считывания финансовых операций из Excel принимает путь к файлу Excel в качестве аргумента
### В проект добавлены два модуля содержащие следующие функции *(12_1)*
* convertor_json - функция, которая принимает на вход путь до JSON-файла и возвращает список словарей с данными о финансовых транзакциях
* sum_transaction - функция, которая принимает на вход транзакцию и возвращает сумму транзакции (amount) в рублях
### В проект добавлен декоратор, ведущий логирование работы функций и выводящий информацию в консоль или txt файл
